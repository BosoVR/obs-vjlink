## Kontext

User wollte das Pad-System überarbeiten: Edit-Mode, Banks A/B/C, eigene Labels und Farben, Drag&Drop Reorder. Außerdem ein GPU-Quality-Slider und ein Effect-Favorites-System.

Hinweis: Direkt nach diesem Tag berichtete der User, dass mehrere neuere Effekte nicht laden. Das GitHub-Release wurde nicht erstellt — stattdessen wurden in v1.3.2 die Bugs gefixt und alles dort released.

---

## Pad System Rework

- **Banks A/B/C**: 3 separate Pad-Sets, umschaltbar
- **EDIT/PLAY Mode Toggle**: im Edit-Mode werden Pads konfiguriert, im Play-Mode getriggert
- **Custom Labels**: User kann eigene Texte pro Pad setzen
- **Custom Colors**: Pad-Farben konfigurierbar
- **Drag & Drop Reorder**: Pads neu anordnen
- **Edit Modal**: Detail-Editor mit Duplicate-Funktion
- **Last-Triggered Indicator**: Visual Feedback welches Pad zuletzt gefeuert wurde
- `let perfPads = []` Mirror-Variable (statt Top-Level-Getter, der JS-Syntax-Fehler verursachte)

## GPU Quality Slider

- Web-UI Slider: LOW / MEDIUM / HIGH
- Backend: neuer WebSocket Vendor Request `SetQuality`
  ```c
  static void handle_set_quality(...) {
      int q = (int)obs_data_get_int(request_data, "quality");
      ctx->gpu_quality = clamp(q, 0, 2);
  }
  ```
- Datei: `src/controls/websocket_handler.c`

## Effect Favorites

- Stern-Icon pro Effect-Card zum Markieren
- Hover-Tooltips mit Beschreibung
- Persistent in `localStorage`
