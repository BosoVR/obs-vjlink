## Kontext

Direkt nach v1.3.1 hat der User berichtet, dass mehrere Effekte überhaupt nicht laden (HLSL-Compile-Fehler) und einige andere visuell schlecht aussehen. v1.3.1-Tag war zwar gepusht, das GitHub-Release wurde aber nicht erstellt. Stattdessen wurden die Bugs gefixt und alles zu v1.3.2 gebündelt.

---

## Fixed (HLSL Compile Errors — luden nicht)

### Bloom Pro
- Problem: Array-Initializer `float weights[7] = { 0.198596, 0.175713, ... };` wird vom OBS-HLSL-Compiler nicht unterstützt
- Fix: Ersetzt durch separate `const float`-Variablen + `ring(uv, px, i, w)` Helper-Funktion

### Type Animator
- Problem: `int rows[7] = {0, 0, ...};` Array-Init **und** `out int letters[12]` Output-Array-Parameter
- Fix: Komplett neu geschrieben ohne Arrays:
  - `glyphRow(letter, row)` Funktion gibt 5-bit Row-Pattern direkt zurück
  - `wordLetter(choice, pos)` Funktion gibt einzelne Buchstabe zurück
  - `wordLength(choice)` separate Helper

### Witch Sigil
- Problem: Conditional Loop-Bound `for (int j = i + 2; j < 5 + ((i == 0) ? 1 : 0); j++)` verhindert Loop-Unrolling
- Fix: Manuelle Edge-Aufzählung via `sdPentagramEdge(p, a, b, r)` Helper:
  - 5 explizite Aufrufe (0→2, 1→3, 2→4, 3→0, 4→1)
  - `min` über alle 5 Distanzen

### Concrete Pulse
- Problem: Referenz auf `beat_1_16` Uniform, das **nicht deklariert** war
- Fix: `beat_1_16`-Branch entfernt, beat_sync Range von 0-3 auf 0-2 reduziert (Continuous/1/4/1/8)

### Liquid Sim
- Problem: `float2x2 rot = float2x2(0.8, 0.6, -0.6, 0.8); ... mul(p, rot)` — Matrix/Vector-mul Path-Issue
- Fix: Rotation inline ausgeschrieben:
  ```hlsl
  float c = 0.8, s = 0.6;
  float2 rp = float2(p.x * c - p.y * s, p.x * s + p.y * c);
  ```

### Glitch Basic
- Problem: vermutlich der ungenutzte `texture2d audio_tex` Uniform
- Fix: Uniform entfernt
