## UX Wins

### `bg_disable` Toggle in 8 Effekten

Neuer uniform `float bg_disable` (0=show, 1=hide) in:

| Effect | Was bei `bg_disable=1` verschwindet |
|---|---|
| `cyber_grid.effect` | Stars + Horizon-Glow → reines Tube-Grid |
| `vaporwave_sunset.effect` | Sky + Sun + Mountains + Stars → nur Grid |
| `concrete_pulse.effect` | Concrete-Surface + Block-Grid → nur Cracks + Shockwave |
| `witch_sigil.effect` | Smoke-Base → nur Sigil-Linien + Drips + Eye |
| `type_animator.effect` | BG-Stripes + Random Rectangles → nur Text |
| `liquid_sim.effect` | Full-Screen Palette-Fill → Alpha = nur Caustic + Ridge Mask |
| `holographic_foil.effect` | (standalone) Foil-Base → nur Sparkles + Streaks |
| `iridescent_mesh.effect` | Iridescent Surface → nur Highlights + Specular |

Alle Web-UI-Param-Listen + JSON-Metas entsprechend aktualisiert.

### Master "STOP ALL AUTO" Button

Roter Button oben im Auto-VJ/AI-Panel. Ein Klick:
- Setzt `setAutoVj(false)` und uncheckt die Checkbox
- Ruft `setAiMode('off')`
- Cleared pending beat-quantize switches (`pendingEffect`, `pendingPalette`)
- Visual Flash auf dem Button als Feedback

### AI Status Badge verbessert

Größer und farbcodiert:
- **OFF**: grau (`#222 / #888`)
- **LEARN**: grün (`#1a4d1a / #9f9`)
- **PLAY**: magenta (`#4d1a4d / #f9f`)

## Type Animator Custom Text System

### Shader-Erweiterung

- Glyph-Tabelle erweitert von 15 auf **38 Zeichen**:
  - A-Z (Indizes 1-26)
  - Space (Index 27)
  - 0-9 (Indizes 28-37)
- 12 neue uniforms `text_char_0` bis `text_char_11` (jeweils 0-37)
- Neuer Mode `text_choice == 6` = CUSTOM, liest aus diesen Uniforms
- Funktion `customCharAt(pos)` für direkten Zugriff
- Funktion `customLength()` zählt Wortlänge bis zum ersten leeren Zeichen

### Web-UI Custom Words Sub-Panel

Erscheint automatisch wenn `activeEffect === 'type_animator'`:
- **Toggle**: "Use Custom Words"
- **Textarea**: max 8 Wörter à 12 Zeichen, sanitized auf A-Z + 0-9 + Space
- **Dropdown** Rotation:
  - Manual (no rotation)
  - Rotate every 4 beats
  - Rotate every 8 beats
  - Rotate every bar
  - Rotate every 2 bars
- **▶ Next Word** Button für manuellen Wechsel
- Active-Word Anzeige
- Persistent in `localStorage` unter Key `vjlink_custom_words_v1`

### Rotation-Logic

- `tickCustomWords(state)` in `updateState`-Hook
- Beobachtet `state.beat_count`
- Bei Erreichen des Intervalls: `currentIndex` weiterschalten, neue 12 SetParam-Calls senden
- `pushCustomWordToShader(word)` encodiert das Wort und sendet `text_char_0..11`

## Visuelle Überarbeitung mit Web-Referenzen

### Cyber Grid → Pure Neon Wave (radikaler Redesign)

**Referenzen**:
- [Wikipedia Synthwave/Outrun](https://en.wikipedia.org/wiki/Synthwave) — "laser grid" extending to vanishing point
- [Synthwave Aesthetics Wiki](https://aesthetics.fandom.com/wiki/Synthwave) — neon-grid landscapes
- [SpoonGraphics Cyberpunk Tutorial](https://blog.spoongraphics.co.uk/tutorials/how-to-apply-cyberpunk-style-color-grading-neon-effects-to-your-photos) — white-center → colored-outline → outer-glow tube glow

**Implementation**:
- Komplett entfernt: Sky-Gradient, Sonne, Stars (außer top-third bei bg_off=0), Ground-Fill
- Pure perspective grid, vanishing point in der Mitte
- Neue Funktion `tubeGlow(d, w, col)` mit 3-Layer-Falloff:
  - **Core**: `exp(-d² / w²·0.25)` — schmaler weißer Hot-Core
  - **Mid**: `exp(-d / w·1.6) * 0.85` — farbige Mitte
  - **Halo**: `exp(-d / w·6.0) * 0.35` — weiches äußeres Glühen
- Hot-Color (Magenta) für H-Lines, Cool-Color (Cyan) für V-Lines
- Beat-Pulse: Jede 4. Linie wird kurz pure white auf Beat
- Bass expandiert Tube-Radius temporär
- Sättigung-Boost: `lerp(grey, col, 1.30)`

### Vaporwave Sunset → True Synthwave

**Referenzen**:
- [Wikipedia Synthwave](https://en.wikipedia.org/wiki/Synthwave) — Outrun aesthetic
- [Synthwave Aesthetics Wiki "Retrosun"](https://aesthetics.fandom.com/wiki/Synthwave) — setting sun composed of horizontal stripes, bright yellow → deep magenta gradient
- [Aesthetics of Design — Synthwave](https://www.aesdes.org/2024/01/24/aesthetics-exploration-synthwave/) — high-contrast Neon Noir
- Shadertoy: [Synthwave grid](https://www.shadertoy.com/view/dt2SDt), [retrowave](https://www.shadertoy.com/view/7lyGzh)

**Implementation**:
- Sun-Default vergrößert von 0.32 → 0.42
- Slits decken jetzt **gesamte Disk** ab (vorher nur untere Hälfte)
- Slit-Density 18-36 (mehr Linien für authentischen Look)
- 3-Stop Sky: deep-purple top → magenta mid → hot-pink bottom
- 3-Stop Sun: yellow top → orange mid → magenta bottom
- Stars nur in oberen 35% der Sky, sparser
- **Dual-Color Grid**: `grid_h` (Magenta) horizontal + `grid_v` (Cyan) vertikal — Outrun Signature
- Triangulare Wireframe-Mountains via `mountainSilhouette()` Funktion (5 Peaks mit Hash-basierter Variation)
- Mountain-Edge mit Cyan-Glow
- Film-Grain entfernt (matschig)
- Sättigung-Boost: `lerp(grey, col, 1.30)`

### Holographic Foil → Cyanilux-style Diffraction

**Referenzen**:
- [Cyanilux Holofoil Card Shader Breakdown](https://www.cyanilux.com/tutorials/holofoil-card-shader-breakdown/) — kanonische Implementation
- [Foilco — Holographic Foil](https://www.foilco.com/holographic-foil/) — physikalische Basis: vapor-deposited Aluminium + embossed micro-grooves als diffraction grating
- [Alan Zucconi CD-ROM Shader](https://gist.github.com/wayabi/a38e0154c9aaac3a36f9d2f97ff8572b)

**Implementation** (5 Layer):
1. **Pseudo-Tangent-Space View Direction** — synthetisch aus UV-Gradient + Audio-Wobble
2. **Parallax-like UV Distortion** — Low-freq FBM Noise verschiebt LUT-Koordinaten
3. **Repeating Rainbow LUT** — `rainbowLUT(t, pid)` mit Cosine-Palette, wraps cleanly
4. **Microstructure Facets** — 50×50 Grid, jede Facette mit `hash21(facet_id)` Random-Tilt, biased Diffraktion
5. **Anisotropic Specular Streaks** — `pow(sin(rotated_uv.x * 380 + facet_n*6), 14)` — schmale helle Bänder
6. **Specular Sparkles** — Hash-basiert, "winken" zufällig

Im Filter-Modus: input-luminance perturbiert LUT-t für view-angle-feel.

### Iridescent Mesh Polish

- Default `surface_scale` von 1.5 → 2.5 (mehr Surface-Variation)
- Specular-Pow erhöht von 24 → 32 (schärfere Highlight-Peaks)
- Zusätzliche Spec-Bloom-Schicht mit pow=8 für Chrome-Look
- Sparkle-Threshold von 0.985 → 0.978 (mehr Sparkles)
- `bg_mode` durch `bg_disable` ersetzt für Konsistenz mit anderen Effekten

### Mono Outline Polish

- Default `threshold` von 0.18 → 0.12 (stärkere Edges out-of-the-box)
- Neuer Param `kernel_size` (0=3x3 fast, 1=5x5 cleaner)
- 5x5 Modus:
  - Zusätzlicher `edge_wide` Sample bei px*4
  - Box-Filter Smoothing (4 Off-Center Samples) reduziert Jaggies
  - 0.4 Blend zwischen edge und e_avg
