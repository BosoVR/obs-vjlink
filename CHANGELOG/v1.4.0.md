# v1.4.0 - UI, Settings, 3D Mesh Path, Effect Automation

**Datum**: 2026-05-17

**Tag**: `v1.4.0`

## Highlights

- Full Web UI overhaul with Basic/Pro structure, settings drawer, compact/performance modes, profile save/load, and autosave improvements.
- Backend-owned state save/load path so settings are restored more consistently across sessions.
- Expanded per-effect settings metadata and validation contracts for the upgraded effect control surface.
- AudioLink-style automation controls for effect parameters, including amount, threshold, curve, and smoothing.
- Pad system improvements for flash/effect triggering, banks, labels, colors, and blend controls.
- Strobe and flash effects improved with onset-aware triggers, safety controls, and better hardtechno timing.
- New true 3D render path for mesh-based visuals with depth-enabled render targets, perspective projection, and no-black fullscreen fallback.
- Added `Logo Extrude 3D`, `Halo Text Logo Tunnel`, and `Brutalist Scan Glitch`.
- Halo text defaults to `BOSO` and supports custom encoded ring text lanes.
- Broad visual and parameter pass across existing effects, including Type Animator, Vaporwave Sunset, Sphere Field, Bloom Pro, Holographic Foil, Mono Outline, Pixel Sort, Basic Glitch, and Snare Flash.
